# DriftiX - AI-Powered Local Services Search

DriftiX is a modern, AI-enhanced search platform for discovering local services. Built with Next.js, TypeScript, and Tailwind CSS, it offers an intuitive interface with smart suggestions and real-time filtering.

## ✨ Features

### 🔍 Smart Search
- **AI-Powered Suggestions**: Context-aware results with rich metadata
- **Real-time Filtering**: Instant updates as you type
- **Service Detection**: Automatically categorizes searches (food, rides, etc.)
- **Location Awareness**: Smart local results with distance indicators

### 📱 Mobile Experience
- **Sticky Search Bar**: Always accessible at the bottom
- **Swipeable Results**: Natural-feel drawer with spring physics
- **Voice Input**: One-tap voice search
- **Full-Screen Overlay**: Clean, focused search interface
- **Smart Location Pings**: "You're here" indicators
- **AI Summary Bar**: Contextual result summaries

### 🎨 Modern UI
- **Rich Cards**: Icons, ratings, and status indicators
- **Smooth Animations**: Spring-based transitions
- **Responsive Design**: Optimized for all devices
- **Dark Mode**: Easy on the eyes

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/driftix.git
   cd driftix
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Visit `http://localhost:3000`

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
